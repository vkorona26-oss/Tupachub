Supported games

Built for the four that matter.

PS99auto

Pet Simulator 99!

Auto-hatch fires the egg prompts in range. Auto-collect touches coin and gem parts. Clicker and rebirth prompts on tap.

PGOauto

Pets GO!

Same layout as PS99: eggs hatch on prompt, coins collect on touch, radius tuned for spawn areas.

GaGauto

Grow a Garden

Plant, harvest and sell through plot prompts. Auto-collect picks crops and fruit without walking the rows.

ETFBauto

Escape Tsunami for Brainrots

Collect brainrot parts on touch, fire escape interactions, and move faster when the wave is close.

Game detection reads game.Name and the marketplace product name — no hardcoded PlaceIds, so a rename never breaks it.

Features

One menu, six things done right.

Game presets

The Game tab detects the place and arms the right prompt and collect filters in one tap.

Farm toolkit

Auto prompts, auto touch collect, auto click, auto keypress — with radius and name filters.

Scanners

List every ProximityPrompt, collectible part and RemoteEvent, then fire or copy straight from the list.

Mobile first

The window scales to your screen, drags by touch, and a floating T button opens it.

Executor 3-8

Every optional API is probed at boot. Missing ones switch off their widget instead of erroring.

Configs and unload

Save your flags to disk, load them next session. Unload restores lighting, FOV, speed and every connection.

Docs

Three things worth knowing.

Opening the menu

RightShift toggles the window on PC. On mobile, tap the floating T button. Rebind it in Settings.

Unloading

Press the close button, or run getgenv().Tupachub.Unload(). Walk speed, FOV, lighting and ESP are restored.

When a game fights back

Open Farm → Scan Remotes, find the action, then fire it from the remote panel with your own arguments.
